Passkeys & device binding demo

NestJS + Better Auth on localhost. Server log prints 2FA codes. The trusted-device checkbox is a cookie. "Bind this device" stores a non-extractable P-256 key in this browser.

1. Email / password
2. Passkey (WebAuthn)
3. Second factor (OTP and trusted-device cookie)
4. Device key (proof of possession)
